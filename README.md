# SAZY SHOP — аукцион в Telegram

Мини-приложение: пользователи выставляют вещи на аукцион на 24 часа, остальные делают ставки.
Стек: Node.js, Express, PostgreSQL, grammY. Деплой: GitHub + Railway.

## Как это работает
- **Выставить лот:** фото, название, размер, стартовая цена, минимальный шаг, город для личной встречи, контакт владельца, описание.
- **Оплата размещения:** 50 ⭐ (автоматически, лот публикуется сразу) или 3 BYN переводом (админ подтверждает в разделе «Админ → Оплаты BYN»).
- **Торги:** 24 часа с момента публикации. Шаг ставки от «минимального шага» лота до 10 BYN. Первая ставка — от стартовой цены до старт + 10 BYN.
- **Поднятие лота:** 25 ⭐, лот переезжает в начало списка.
- **Итоги:** по окончании бот пишет победителю контакт владельца и город, а продавцу — профиль победителя.
- Уведомления: «вашу ставку перебили», «новая ставка на ваш лот», «лот опубликован».
- Админ видит вкладку «Админ»: подтверждение оплат, снятие лотов, бесплатная публикация.

## Переменные Railway
| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | ваш числовой Telegram ID (несколько через запятую) |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `SHOP_NAME` | название |
| `CHANNEL` | username канала для аватарки (без @) |
| `PAY_BYN_INFO` | реквизиты для оплаты 3 BYN |
| `FREE_LISTING` | `true` (по умолчанию) — размещение бесплатно; `false` — платное (звёзды / 3 BYN) |
| `LISTING_STARS`, `BUMP_STARS`, `LISTING_BYN`, `MAX_STEP`, `AUCTION_HOURS` | необязательно, свои цены и правила |

Оплата звёздами (Telegram Stars) работает у любого бота, дополнительных платёжных токенов не нужно.
Если лот отменили, пока шла оплата, звёзды возвращаются автоматически.

## Локально
```bash
npm install
export DATABASE_URL=postgres://user:pass@localhost:5432/shop
export DEV_USER_ID=123456789 ADMIN_IDS=123456789
npm start
```
(без бота звёзды в dev-режиме недоступны; админ может публиковать лоты бесплатно)

## Заметки
- Старые таблицы магазина остаются в базе и не используются.
- Бот работает через long polling, запускайте один экземпляр.
- Оплата 3 BYN подтверждается вручную: переводы автоматически не проверяются.
