# LOT24 — аукцион в Telegram

Node.js + Express + PostgreSQL + grammY. Деплой: GitHub -> Railway.

## Возможности
- Сроки торгов: 24 ч бесплатно, 2 дня — 10 ⭐, 3 дня — 15 ⭐
- Автопост нового лота в канал (фото + ссылка + кнопка «Сделать ставку»); пост обновляется, когда торги закончились/лот снят
- Ссылка на лот: `https://t.me/БОТ?start=lot_ID` (или `/APP_SHORT_NAME?startapp=lot_ID` при заданном APP_SHORT_NAME)
- Уведомления: перебили ставку, новая ставка продавцу, итоги; напоминания за 1 час и 15 минут; ежедневный дайджест
- Антиснайпер: ставка в последние 5 минут продлевает торги
- /mute, /unmute; админ: /stats, /backup, /broadcast текст, /post ID

## Сохранность лотов при обновлении кода
Все данные лежат в PostgreSQL на Railway, а не в коде. Обновление через GitHub пересобирает только приложение;
таблицы не удаляются (миграции только `CREATE IF NOT EXISTS` / `ADD COLUMN IF NOT EXISTS`).
Не удаляйте сервис Postgres и не меняйте `DATABASE_URL`. Делайте `/backup` в боте перед крупными изменениями.
